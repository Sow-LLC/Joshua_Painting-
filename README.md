# Joshua's Painting Service — painting company site + job manager

An original painting-contractor website with a full back end for running the business.
It borrows the *approach* of Maison Margiela (all-white palette, deconstruction, construction
left visible, archival numbering), not its assets. The house motifs here are our own:
a half-painted wall with masking tape and pencil notes, services coded
`JP / 01…05`, and the method shown as a wall in cross-section. No fonts or marks are
copied from anyone.

**Photos:** the site now uses only real job photos (`public/img/work/`). The early
AI-generated illustrations were removed from `public/img/` (Nov 2026); their source PNGs
are still in `photos-src/` (not in git).

**English / Español.** The public site has an EN / ES switch in the header. English is written in
`public/index.html`; the Spanish lives in `public/js/i18n.js` (edit wording there, keyed by each
element's `data-i18n` name). The first visit follows the browser's language, the choice is remembered,
and `/?lang=es` links straight to Spanish. Quotes record the language used, and Spanish ones are
flagged "ES" in the dashboard so you know to reply in Spanish. The studio dashboard stays English.

**Layout.** Photos pop up and sections fade in as you scroll (`public/js/reveal.js`; off for visitors who ask their device for reduced motion). The services are a grid of photo cards,
each showing a finished job (three per row on a computer, one per row on a phone). An earlier
scroll-animated version was tried and dropped; old `/static/` links now redirect to the home page.

**Business pages:** promises (free written estimates, warranty, clean-up), its own Contact page with
the quote form, FAQ and Reviews pages, and a Call / Free quote bar pinned to the bottom of phone screens.

Everything except `/` and `/admin/` is **generated**. Shared sections (about, method, service area, FAQ,
quote form) live in `tools/sections.html`: edit the text in


`<generated-pages>` markers, and writes `sitemap.xml` and `robots.txt`. Each service
page has its own quote form with that service already picked.

### Quote alerts (ntfy)

Every new quote request sends a push alert through [ntfy](https://ntfy.sh) (free, no account)
with the full request: name, phone, email, address, job and message, plus **Call**, **Email** and
**Job manager** buttons. Anyone who knows the topic name can read the alerts, and ntfy.sh keeps
each one for about 12 hours, so **keep the topic name secret** (it is in `.ntfy-topic`).

1. Pick a hard-to-guess topic name, e.g. `jps-quotes-` + random letters.
2. `npx wrangler secret put NTFY_TOPIC` and paste it.
3. On Joshua's phone: install the **ntfy** app → **+** → subscribe to the same topic.

No topic set = no alerts (local development stays quiet).

## Stack

One Cloudflare Worker serves everything:

- `public/`: static site (`index.html`) and the studio dashboard (`admin/`)
- `src/worker.js`: JSON API under `/api/*`
- D1 (SQLite): `schema.sql`, with tables `quotes`, `jobs`, `estimates`, `estimate_items`, `schedule`, `crews`, `activity`

## What the back end does

| Area | Behaviour |
|---|---|
| **Quote requests** | Public `POST /api/quotes` (JSON or plain form POST). Validation, a hidden honeypot field, and a no-JS fallback that redirects to `/?sent=1`. |
| **Job board** | Kanban: lead → estimated → scheduled → in progress → done / cancelled. Drag cards between columns. Converting a quote creates job `JP-0001`, `JP-0002`… with the request details copied into its notes. |
| **Estimates** | Line items of three kinds. **area** (sq ft × rate, plus paint = sq ft × coats ÷ coverage × $/gal), **unit** (doors, cabinets), and **flat**. Then discount, tax and gallons needed. Totals are always recomputed on the server. Accepted estimates are locked, and each one is printable. |
| **Scheduling** | Book crews on date ranges. Overlapping bookings for the same crew return `409` with the clashes, and the dashboard offers to double-book anyway. There's a two-week calendar by crew. |
| **Automation** | Drafting an estimate moves a lead to *estimated*, and booking a crew moves it to *scheduled*. Status only moves forward automatically. Every change is written to the job's activity log. |
| **Dashboard** | New quotes, open jobs, pipeline value (latest non-rejected estimate on every open job) and the next 14 days of bookings. |
| **Auth** | All `/api/admin/*` routes need `Authorization: Bearer <ADMIN_KEY>`, checked with a constant-time compare. The dashboard keeps the key in `sessionStorage` only. |

The full route list is in the header comment of `src/worker.js`.

## Run locally

```bash
npm install
npm run db:local      # create local D1 tables + two starter crews
npm run dev           # http://localhost:8787   (dashboard: /admin/)
npm test              # 16 end-to-end API checks against the running dev server
```

The local admin key is in `.dev.vars` (gitignored).

## Phone experience (Nov 2026)

- **Quote form, step by step** (`public/js/site.js`): 1 pick the job (tap a tile, moves on by itself) →
  2 details, all optional → 3 name and phone → thank-you screen. From a service page it starts at step 2.
  Without JavaScript the same form shows all at once and still posts.
- **Full-screen menu** on phones; Services folds open with +. One quote button per screen: on phones the
  header has no Quote button (the bottom bar has it), and on /contact/ the bar shows only Call.
- **Our work** (`/work/`): one chapter per job type (Exterior, Interior, Decks & waterproofing, Commercial,
  Prep & repair), each a single swipeable row of photos at the same height, so uneven photo counts look
  intentional. Category comes from the last field in `PHOTOS` (`tools/build_pages.py`).
- **Photo viewer** (`public/js/lightbox.js`): tap any job photo for full screen; swipe or ← → to move,
  swipe down / Esc / ✕ to close. On /work/ it stays within that job type.
- **Front page panels:** each of the six services is a full-screen panel (photo, name, one line,
  Free quote + See details), and the page snaps to each one once the visitor starts scrolling.
  Panel photos are set in `PANEL_PHOTO` in `tools/build_pages.py`. On phones the Call / Free quote
  bar hides while the opening screen or a panel fills the screen (they have their own buttons).
- **Smooth page changes** (CSS view transitions), **press feedback** on taps, and on phones the header
  hides while scrolling down and returns on scroll up. All motion is off for "reduce motion" devices.
